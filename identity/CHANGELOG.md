# Changelog

All notable changes to `@avantf/dsh-identity` are documented here. 用户可观察的行为才进这份文件
（对外 wire / 设置页 / 提示词正文 / 发布面 / 升级行为）；仓库内部重构不进。

## [Unreleased]

## [0.1.0] - 2026-10-12

首个版本。

### Added

- **用三个文件替换系统提示词里的「身份」段**：`harness:identity` 与 `deployment:persona-prefix` 两段被
  `IDENTITY.md` → `SOUL.md` → `RULES.md` 的**非空**正文替换（段间一个空行）；其余 section、`tools` 与上下文
  快照**一条不少、一字不改**。三个文件全空或总开关关闭 ⇒ 提示词与未装本插件时逐字相同；子代理与 Agent Teams
  成员**完全不受影响**（默认只替换主会话）。
- **设置页「身份」**（`settings.section`，order 25）：总开关、三个文件编辑器、身份下拉（含删除预设）、
  「恢复预设原文」「存为新预设」，两个弹窗都是页面内的（不用 `window.confirm` / `prompt`）。
- **多语言内置预设**：`coder` / `assistant` / `analyst`，各含 `zh` 与 `en`；首次运行释放到数据根
  `identity/presets/`，**只补缺失、永不覆盖**（删掉的预设不会被重建）。
- **首次打开开关时落地一份可用身份**：该 profile 还没有身份文件时，用 `assistant` 预设写入生效目录；
  已有内容时**不做任何事、永不覆盖**。
- **切换身份可逆、按 profile 隔离**：离开某身份时把它当前的内容存成"你在本 profile 的该身份版本"
  （`profiles/<profile>/.edits/<id>/`），切回来恢复的是你那份；预设库本身永不被编辑改写。手写内容没有对应
  identity id 时切走会被**拒绝**（提示先「存为新预设」），不静默覆盖。
- **会话内冻结**：一个会话用哪个身份取决于它开始时磁盘上是什么；中途改文件 / 应用预设 / 动开关都不影响它，
  下一个会话才读到新内容。
- **`RULES.md` 那一段带一行标题**：中文正文 `**规则**`、否则 `**Rules**`（跟随正文语言，不跟界面语言）；
  该段为空时连标题一起省；字节预算按**含标题的整段文本**计。设置页编辑的仍是文件原文，不含标题。
- **预算与降级**：渲染后的身份默认上限 64 KiB，超出整体截断并在末尾追加可见提示、日志点名超限文件；
  数据目录只读、预设资源缺失等环境故障只写一条 WARNING，插件照常挂载（**绝不拒载、绝不杀宿主**）。
- **`{{...}}` 默认按字面量保留**（打开「插值」后才走上游严格插值语义；dsh `0.1.5` 线那代的 system-prompt
  不认识这个开关，永远按严格插值处理）。与 `dsh-persona` 的 `complete: true` 不再冲突。
