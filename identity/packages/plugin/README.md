# @avantf/dsh-identity

用你自己的三个文件替换 DSH（DeepSeek Harness）系统提示词里的**身份部分**。

装好后，设置面板多出一个**「身份」页**：一个总开关、三个可编辑的文件、一个多语言的预设库。打开开关，
会话的系统提示词就以你的身份文件开头；关掉开关，提示词与没装这个插件时**逐字相同**。

## 主要功能

- **三个文件就是提示词**：`IDENTITY.md`（你是谁、叫什么、扮演什么角色）、`SOUL.md`（语气、价值观、
  行事风格、判断取舍的原则；设置页里显示为「性格」）、`RULES.md`（硬约束）。按这个顺序拼接**非空**
  正文，段间一个空行，没有 frontmatter；只有 `RULES.md` 那一段会被加上一行标题（正文是中文时
  `**规则**`，否则 `**Rules**`），好让硬约束在一段长提示词里一眼可辨。
- **只替换两段，其余一字不改**：`harness:identity` 与 `deployment:persona-prefix`。工具指引、
  Agent Teams、plan mode、goal、subagent、jobs、web、workflow、MCP 等所有其它 section，以及 `tools`
  与上下文快照，**一条不少、一字不改**；子代理与 Agent Teams 成员看到的提示词与没装时相同（默认只在
  主会话替换）。
- **设置页「身份」**：总开关、三个文件编辑器、身份下拉（选中即应用，带二次确认）、「保存」「存为新预设」、
  「恢复预设原文」，以及删除预设。
- **内置多语言预设**：`coder` / `assistant` / `analyst`，各含中文与英文两套；首次运行释放到数据目录，
  **只补缺失、永不覆盖**——你删掉的预设不会被重新建出来。
- **首次打开开关就有一份可编辑的身份**：这个 profile 还没有任何身份文件时，用 `assistant` 预设落地
  一份；已经有内容时**一个字都不写**。
- **换身份可逆、按 profile 隔离**：切换身份时，你写的那一版会按 profile 存下来；切回来恢复的是**你那份**，
  不是预设原文。预设库本身不会被你的编辑改写。

## 接入 dsh

```bash
# 把插件装进你要用的 profile（依赖会自动装好，不用管别的）
dsh plugin --profile <PROFILE> add @avantf/dsh-identity@<version>

# 然后重启 dsh 生效
```

版本号可以不写，但建议指定一个明确版本。

**DSH Desktop**：在「插件」页里安装同一个包即可，装完重启应用；不用动命令行。

## 怎么用

打开**设置 →「身份」**，先打开「启用身份」，然后在三个框里写你的身份，点保存——**新会话生效**。

想换个身份，就在「身份」下拉里选一个（按你当前的语言取那一套，缺该语言时退回英文）。你写过的内容不会
因为切走而丢：下次切回该身份，恢复的是你那份；要拿回预设自带的文本，用「恢复预设原文」。手写内容还没有
对应的身份 id 时，切走会被**拒绝**（提示先「存为新预设」），插件宁可拒绝也不静默覆盖你写的东西。

要改某套预置的原文，直接编辑数据目录下 `presets/<id>/<locale>/*.md`；「存为新预设」则把当前生效身份
另存成一个新的预设 id。

几个边界：

- 三个文件都清空、或关掉开关 ⇒ 新会话回到原生提示词。
- **改动在新会话生效**：当前会话进行中改文件、应用预设、动开关都不影响它。
- **默认只在主会话替换**：子代理与 Agent Teams 成员的提示词与没装时逐字相同。
- `{{...}}` 默认按**字面量**保留；打开「插值」后按上游的严格插值语义处理——文件里引用了没注册的变量会让
  **那一次装配失败**（默认关闭）。唯一的例外是 dsh `0.1.5` 线：那一代的 system-prompt 不认识这个开关，
  **永远按严格插值处理**，所以在那上面别在文件里写完整的 `{{name}}`。
- 渲染后的身份默认上限 64 KiB，超出会截断并在末尾追加一行可见提示。

## 配置与数据

- **数据目录**：默认 `~/.avantf`，环境变量 `AVANTF_HOME` 可以改变它。
- **布局**：

  ```
  <数据目录>/identity/
    profiles/<profile>/{IDENTITY,SOUL,RULES}.md     # 这个 profile 生效的身份
    presets/<id>/<locale>/*.md                      # 预设库（可自己编辑）
  ```

- **按 profile 隔离**：不同 profile 各有各的身份，互不影响。
- **环境故障只降级、不拦路**：数据目录只读、预设资源缺失这类问题只写一条 WARNING，插件照常挂载。

## 升级 / 卸载

```bash
# 升级：换版本号重装同一个包
dsh plugin --profile <PROFILE> add @avantf/dsh-identity@<version>

# 卸载
dsh plugin --profile <PROFILE> remove @avantf/dsh-identity
```

两者都要重启 dsh 生效。卸载**不动数据目录**：你写的身份文件与预设库全部保留。DSH Desktop 在「插件」
页上卸载。
